# Abstraction vs Encapsulation in C#
============================

* Purpose :

Abstraction - Hide implementation details.
Encapsulation - Protect and restrict access to data.

* Hides :

Abstraction - How somethings works.
Encapsulation - Internal data (variables).

* Focus :
Abstraction - On what to do.
Encapsulation -  On how to protect data.

* Used via :

Abstraction -  abstract class, interface
Encapsulation - private fields + get/set methods

* User sees :

Abstraction - Only necessary methods.
Encapsulation - Only allowed data access.

* Real life :

Abstraction - TV remote : you press button, don't know inside circuit.
Encapsulation - ATM : You can only withdraw, can't change internal code.

* Goal :

Abstraction - Simplify interface for user
Encapsulation - Ensure data integrity and control access
