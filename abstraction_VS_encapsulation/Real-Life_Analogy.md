
# Abstraction :

* Bike ka clutch dabate hein  -> bike chlati hai
* Clutch ke andar kya cable, kaise engine engage hai  -> sab chhupa hai

# Encapsulation :

* Mobile me PIN lagate hai -> phone ka access protected hai
* Andar ke apps ko bina unlock kiye nahi chhed sakte

# One line to remember :

* Abstraction = "kya krna hai" batata hai, kaise karna hai chhupata hai
* Encapsulation = "kaise access karna hai" control karta hai, data chhupata hai
